# Django Task Manager

A basic task management web application developed using Django and Python.

## Technologies Used

- Python
- Django
- SQLite
- HTML
- CSS
- Bootstrap

## Features

- Add Tasks
- Edit Tasks
- Delete Tasks
- Mark Tasks as Completed
- Due Date Management
- Task Priority Handling
- Django Admin Panel

## Project Structure

- Django models for database management
- Views for backend logic
- Templates for frontend rendering
- SQLite database integration

## Tools Used

- VS Code
- Django
- SQLite

## Future Improvements

- User Authentication
- Task Categories
- Search and Filter Options
- Better UI Design

## Note

This project was developed for learning Django fundamentals, CRUD operations, and backend web development concepts.
